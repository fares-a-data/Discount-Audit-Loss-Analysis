# Discount-Audit-Loss-Analysis
Interactive data analysis dashboard auditing the financial impact of discount policies, identifying high-loss products and regions, and providing actionable recommendations to optimize profit margins.
# Executive Loss Impact & Discount Audit

![Dashboard Image](حط_رابط_الصورة_الأولى_هنا)
## 📌 Project Overview
This project is an interactive data analysis dashboard that audits the financial impact of discount policies. It highlights loss-making products, cities, and discount brackets, and provides actionable recommendations to optimize profit margins and recover from net deficits.

## 🛠️ Tools & Technologies Used
* **SQL:** Used to answer business questions, extract the core queries, and import the dataset.
* **Power Query:** Used for data cleaning, transformation, and preparation.
* **Microsoft Excel:** Used to create Pivot Tables for initial analysis and data exploration.
* **Power Pivot & DAX:** Utilized to build the data model and create key measures such as `Total Revenue` and `Total Profit`.
* **Power BI:** Used to build the final interactive dashboard and visualize the insights.

![Insights & Recommendations]((https://github.com/fares-a-data/Discount-Audit-Loss-Analysis/blob/main/Screenshot%202026-10-26%20141341.png))
## 📊 Key Insights
* **Overall Financial Performance:** Total Revenue reached **260.52k EGP** with a profit margin of **12.37%** (32.22k EGP net profit).
* **Loss Impact:** Total losses stand at **-35.86k EGP** (13.38% losing margin), absorbing **108.2%** of total generated profits.
* **Discount Analysis:** The **10%-20% discount bracket** is the main driver of margin erosion, yielding a negative margin of -4.77%.
* **Top Losing Products:** Global High-Bac... (at -489.6%) and Office Star... (at -361.3%).
* **Top Losing Cities:** Baton Rouge (at -409.5%) and Chicago (at -389.9%).

## 💡 Recommendations
1. **Restructure Discount Policies:** Immediately discontinue or re-evaluate the high discount bracket (10%-20%).
2. **Conduct Pricing & Cost Audits:** Review product cost structures to ensure prices never fall below total product costs.
3. **Optimize Profitable Brackets:** Focus sales and marketing efforts on safe discount tiers (0%-5% and 5%-10%).
